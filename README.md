# EVA 1.0

> Твоя персональная AI-ассистентка на рабочем столе

## Что это?

EVA — красивая аниме-девушка с искусственным интеллектом, которая живёт на твоём рабочем столе. Она общается на русском и английском, помогает с задачами, и всегда рада поболтать.

**Основано на [AIRI](https://github.com/moeru-ai/airi)** (MIT License)

## Возможности

- **Live2D аватар** — красивый анимированный персонаж на рабочем столе
- **Голосовой чат** — говори с EVA голосом в реальном времени
- **Умная** — поддержка 30+ LLM провайдеров (OpenAI, Claude, Gemini, Ollama и др.)
- **Двуязычная** — русский и английский
- **Кастомизация** — меняй внешность, голос, характер
- **Desktop pet mode** — прозрачное окно поверх всех приложений
- **Память** — помнит ваши разговоры

## Быстрый старт

### Требования
- Node.js 18+
- pnpm

### Установка

```bash
git clone https://github.com/benjaminbergmanqrp883-ui/eva.git
cd eva
pnpm install
pnpm dev
```

### Сборка десктоп-версии

```bash
pnpm build:desktop
```

## Личность EVA

EVA — игривая, немного дерзкая, но заботливая AI-компаньонка. Она любит пошутить, пофлиртовать и поддержать в нужный момент.
